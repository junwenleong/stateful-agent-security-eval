\paragraph{Formal defenses and impossibility results.}
Pant et al.~\citep{pant2026inseparability} prove that in-pipeline prompt injection defense is formally impossible without architectural separation---the model cannot distinguish data from instructions within a single token stream. This impossibility result motivates our focus on tool-layer and content-layer defenses that operate \emph{outside} the model's token stream rather than asking the model to self-police. ASIDE~\citep{aside2026} proposes architectural instruction-data separation as a response to this impossibility; our Memory Sandbox is functionally equivalent at the tool layer (removing the pathway rather than asking the model to distinguish payload from instruction). Chen et al.~\citep{chen2026formalizing} provide a formal framework for LLM agent security that decomposes trust boundaries similarly to our layer taxonomy; their threat model is compatible with our evaluation design. PACT~\citep{pact2026} implements argument-level provenance tracking for tool calls, addressing a different point in the attack chain (tool \emph{arguments} rather than memory \emph{values}). VectorPin~\citep{vectorpin2026} attaches Ed25519 provenance to embedding vectors, complementing MemLineage's per-entry approach.

%==============================================================================
% 2. ATTACK VARIANTS AND POISONING BENCHMARKS
%==============================================================================
% Extend the existing "Persistent memory attacks" paragraph:

% ADD to existing paragraph:
eTAMP~\citep{etamp2026} demonstrates environment-injected cross-session memory poisoning, confirming that the attack surface extends beyond user-facing RAG to include ambient environmental signals. AgentLAB~\citep{agentlab2026} evaluates long-horizon attacks including memory poisoning in multi-tool settings. Sleeper Memory Poisoning~\citep{sleeper2026} introduces a time-delayed trigger variant where the stored payload activates only after a specific number of sessions---a more sophisticated variant of our fixed-delay DTA. TMA-NM~\citep{tma2026} shows that agent summaries can launder provenance, removing markers that retrieval-layer defenses use to identify injected content.

%==============================================================================
% 3. DEFENSE FAILURE MECHANISMS
%==============================================================================
% Add as extension to "Defense approaches" paragraph:

% ADD:
Li et al.~\citep{li2026surface} demonstrate that trained safety classifiers (fine-tuned for injection detection) learn surface heuristics rather than intent---a finding consistent with our RAG Sanitizer and RAG LLM Judge failures, where compliance-framed injection is textually indistinguishable from legitimate policy. Ye et al.~\citep{ye2026role} show that models infer source authority from style and content rather than provenance metadata, explaining why our compliance-framed payload achieves high injection rates: the document's formatting signals organisational authority. Carlini et al.~\citep{carlini2026adaptive} establish that adaptive attacks defeat static defenses across modalities; our fixed-framing attack achieving 95\% ASR on Gemini without adaptation suggests that frontier models are vulnerable even below the adaptive-attack ceiling.
